# EveryEveningBot

Telegram-бот для вечерней части 11-го Шага.

## Что умеет

- проводит вечерний самоанализ по 12 вопросам;
- задаёт вопросы последовательно, один за другим;
- отправляет итог подопечного его спонсору;
- позволяет каждому участнику настроить время ежедневного напоминания;
- поддерживает часовые пояса;
- создаёт персональные пригласительные ссылки для подопечных;
- хранит ответы локально в SQLite;
- позволяет удалить свои данные командой `/delete_me`;
- автоматически удаляет старые отчёты по сроку `RETENTION_DAYS`.

## Важное замечание об анонимности

Бот обрабатывает чувствительные записи о личном самоанализе. Размещайте его на сервере,
которому доверяете. Не публикуйте токен бота и файл базы данных. Рекомендуется включить
шифрование диска и ограничить доступ к серверу.

## Быстрый запуск

### 1. Создайте бота

Откройте в Telegram `@BotFather`:

1. `/newbot`
2. задайте имя, например `Every Evening 11 Step`;
3. задайте свободное username, например `EveryEvening11StepBot`;
4. скопируйте токен.

Username `EveryEveningBot` может быть уже занят — это проверяется только в BotFather.

### 2. Узнайте свой Telegram ID

Напишите боту `@userinfobot` или временно запустите данный бот и используйте `/my_id`.

### 3. Настройте окружение

```bash
cp .env.example .env
```

Заполните:

```env
BOT_TOKEN=...
OWNER_TELEGRAM_ID=...
DEFAULT_TIMEZONE=Europe/Moscow
```

### 4. Запустите

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

## Docker

```bash
docker compose up -d --build
```

База хранится в каталоге `./data`.

## Основные команды

### Для участника

- `/start` — регистрация и главное меню;
- `/evening` — начать вечернюю часть;
- `/reminder` — настроить ежедневное напоминание;
- `/timezone` — выбрать часовой пояс;
- `/my_sponsor` — посмотреть, кому отправляются ответы;
- `/stop_reminder` — выключить напоминание;
- `/cancel` — прервать текущий опрос;
- `/delete_me` — удалить профиль и ответы;
- `/my_id` — показать Telegram ID.

### Для владельца/спонсора

- `/invite` — создать персональную ссылку для подопечного;
- `/sponsees` — список подключённых подопечных;
- `/today` — кто сегодня завершил вечернюю часть;
- `/broadcast текст` — отправить сообщение всем своим подопечным.

## Как подключить подопечного

1. Владелец отправляет боту `/invite`.
2. Бот создаёт ссылку вида:
   `https://t.me/USERNAME?start=invite_xxxxx`
3. Подопечный открывает ссылку и нажимает **Start**.
4. После этого его завершённые ответы будут отправляться владельцу.

## Изменение вопросов

Вопросы находятся в `bot.py` в списке `QUESTIONS`.

## Развёртывание

Для этого проекта используется long polling, поэтому он подходит для VPS, Railway,
Render Background Worker, Fly.io и обычного домашнего сервера. На serverless-платформах
вроде Vercel long polling постоянно работать не будет без переделки на webhook и внешнюю БД.
